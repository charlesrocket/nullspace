# `nullspace`

Tiling window manager for FreeBSD.

## Dependencies

- pkg-config
- meson
- ninja
- wayland
- xkbcommon

## Build

```sh
meson setup build
ninja -C build
```

## Usage

```
river -c ./build/nullspace
```
